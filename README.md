### دليل التشغيل والإدارة من هاتف أندرويد (Android Guide)

#### 1. تشغيل المنصة محلياً
التطبيق مبني بتقنيات React 19 + TypeScript + Vite + Tailwind CSS، ويعمل مباشرة دون أية إعدادات معقدة.
```bash
npm run dev
```

#### 2. إنشاء مشروع Supabase المجاني (Zero-Cost Free Tier)
1. افتح متصفح Chrome على هاتفك وتوجه إلى [supabase.com](https://supabase.com).
2. أنشئ حساباً مجانياً ثم أنشئ مشروعاً جديداً باسم `nursing-graduation-2027`.
3. اختر كلمة سر قوية لقاعدة البيانات والمنطقة الأقرب (مثل Frankfurt أو Mumbai).

#### 3. تشغيل ملف ترحيل قاعدة البيانات (Database Migration)
1. من لوحة Supabase، ادخل إلى قسم **SQL Editor**.
2. انسخ محتويات الملف `src/db/supabase_schema.sql` والصقه في المحرر.
3. اضغط **Run**. سيتم إنشاء كافة الجداول (profiles, graduates, payment_transactions, event_settings, announcements, media_assets, audit_logs) وسياسات الأمان والحماية RLS.

#### 4. إنشاء أول حساب مشرف (Admin Bootstrap)
1. سجل حساب خريج عادي من صفحة التسجيل.
2. من لوحة Supabase في جدول `profiles` أو `graduates`، قم بتغيير حقل `role` إلى `'admin'` وحقل `status` إلى `'approved'`.
3. أو استخدم حساب المشرف الجاهز للتجربة الفورية في الموقع.

#### 5. إدارة المحتوى من الهاتف بدون تعديل أكواد
* **تغيير موعد الحفلة:** من لوحة تحكم المشرف ➔ تبويب "إعدادات الحفل" ➔ اختر التاريخ الجديد، وسيتحدث العداد التنازلي على الفور.
* **إصدار وصل مالي:** اضغط "تسجيل دفعة جديدة" ➔ حدد الخريج والمبلغ بالدينار العراقي (د.ع) ➔ يتولد وصل رسمي برقم تسلسلي يمكن طباعته كـ PDF أو حفظه كصورة.
* **نشر إعلان:** من تبويب "إدارة الإعلانات" ➔ اكتب العنوان والنص والتصنيف وسينشر مباشرة.

#### 6. النسخ الاحتياطي والتصدير (Backups)
* يمكنك في أي وقت تنزيل كشف الخريجين كملف `CSV` متوافق مع Excel.
* يمكنك تحميل نسخة احتياطية كاملة للمنصة بصيغة `JSON` بنقرة واحدة من لوحة المشرف.
